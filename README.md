# Polarization Ray Tracer

MATLAB 顺序几何光线追迹与偏振分析。支持折射、反射、多层膜、离轴光面，以及入瞳、出瞳和像面偏振对照。数值测试使用 MATLAB R2026a。

## 第一部分　如何使用

### 1. 启动与第一次追迹

将工程目录设为工作目录，运行：

```matlab
cd('C:/DEV/Por/PolarizationRayTracer')
prt_gui
```

默认是一套库克三片式镜组，设为 587.56 nm、10 mm 入瞳、无穷远轴上物点。点「运行追迹」，然后在「偏振结果」选择出瞳或像面，或在「三维布局」查看折反射路径。点「载入示例」可恢复这套处方和采样设置。

### 2. 编辑 LDE、膜系与位姿

| LDE 项 | 填写方式 |
|---|---|
| Type | 首尾为 OBJ 与 IMA。中间可用 `Standard` 和 `Even Asphere`。 |
| Radius / Conic | 曲率半径以 mm 为单位，曲率中心在该面的局部 +Z 一侧时为正。0 或 Inf 为平面基底。圆锥常数无单位。 |
| A1–A4 | `Even Asphere` 的偶次矢高项依次为 `A1*r^2 + A2*r^4 + A3*r^6 + A4*r^8`，其中 r 用 mm。 |
| Thickness | 到下一面顶点的有符号轴向间隔，单位 mm。共轴反射后沿 −Z 回程时填负值。 |
| Material | 本面后的传播介质。留空或 `AIR` 表示 n=1；其他透明介质填工作波长下的实折射率。 |
| 反射 Material | `MIRROR` 为理想反射镜，`MIRROR:n,k` 指定实际基底，例如 `MIRROR:1.3474,14.133`。反射后传播介质仍是入射介质。 |
| Clear Semi-Dia. / STOP | 用局部通光半径裁剪。Inf 表示无限口径；最多标一个 STOP，且必须有有限半口径。 |
| Coating | 选中实际光面，点击「编辑膜系」，按入射侧到基底的顺序录入每层 `n、κ、厚度 (nm)`。有膜反射面需要 `MIRROR:n,k`。 |

OBJ 的 Thickness 填 Inf 表示无穷远物点，程序在有限参考面发射平行光线。填有限值时，它表示准直束的发射参考面到第一面的距离。共轴处方的第一面顶点在全局 Z=0。IMA 是最终接收平面。

要建离轴或折转结构，在「三维布局」编辑该行的全局 XYZ 或 Rx/Ry/Rz。该行启用全局位姿后不再跟随厚度，其他行不随它移动。口径 U/V 为母面局部坐标中的通光中心偏移。OBJ 局部 +Z 为入射方向，局部 XY 定义光束采样和入瞳偏振基。

例如，90° 折转可用一个 Radius=0、Material=`MIRROR`、半口径 12 mm 的反射面。分别把 OBJ、反射面、IMA 的全局 XYZ 设为 `(0,0,-5)`、`(0,0,0)`、`(10,0,0)` mm，把 Ry 设为 `0°、−45°、90°`。光线沿 +Z 入射，折到 +X。

### 3. 设置入瞳与输入偏振

- 「设置出入瞳」默认根据 STOP 求共轴有限近轴瞳。离轴或折转系统可手动输入入瞳 XYZ、出瞳 XYZ 和姿态。入瞳方向跟随 OBJ。自动求瞳失败时，像面仍可按 OBJ 发射面追迹，界面会显示提示。
- 均匀输入可选 X、Y、45°、135° 线偏振和左右旋圆偏振，也可在「编辑自定义偏振」选择 Jones、振幅/相位差、椭圆或 Stokes。角度单位是 °。
- 逐点输入用「导入 CSV」。XY 单位为 mm，坐标相对于入瞳局部坐标系。每行是一条光线，坐标不得重复，允许非规则采样；点击「清除」可回到规则光瞳采样。

Jones 示例：

```csv
X_mm,Y_mm,ExRe,ExIm,EyRe,EyIm
0,0,1,0,0,0
0.5,0,0,0,1,0
```

Stokes 示例：

```csv
X_mm,Y_mm,S0,S1,S2,S3
0,0,1,1,0,0
0.5,0,1,0,0,0.5
```

Jones 保留复振幅及点间相位。Stokes 支持部分偏振和零场，须满足 `S0 ≥ 0` 及 `sqrt(S1^2+S2^2+S3^2) ≤ S0`，无法从中恢复点间相干相位。

### 4. 看图、读数和导出

结果栏用「出瞳 / 像面」切换输出面。勾选「输入/输出」可并排查看入瞳与所选输出面，同一指标共用色标。点选散点后，图下方显示坐标、光线号和指标值；点击其他位置或切换视图清除读数。偏振方位角从各平面的局部 +X 轴向 +Y 量到椭圆长轴，±90° 对应同一振荡轴。偏振椭圆图中的切向箭头表示旋向，双向箭头表示线偏振轴。

「三维布局」支持三维、XY、XZ、YZ 视图，默认光轴 +Z 向右。用「起始面」「结束面」裁剪可见光面、玻璃侧壁和光线路径。最多显示 17 条代表光线，完整追迹与导出仍使用全部采样。

| 按钮 | 导出内容 |
|---|---|
| **偏振态 CSV** | 所选出瞳或像面的有效样本。选择 Jones 或 Stokes，表头、列顺序和单位与入瞳导入一致。坐标和偏振分量都使用所选平面的局部 XY。仅有单一复场时提供 Jones。 |
| 诊断 CSV | 逐光线位置、方向、有效标记、光程与输入/输出 Stokes，可保留被挡或在像面相交的光线编号顺序。 |
| 导出 MAT | 模型、光瞳坐标、初始点、各面历史、出瞳与像面结果。 |
| 导出 PNG | 当前出瞳或像面的偏振椭圆图，300 dpi。 |

偏振态 CSV 跳过未到达该平面的光线，保留零场样本。若多个有效光线恰好落在相同坐标，文件不写出，避免生成无法重新导入的重复坐标。可改选出瞳，或导出诊断 CSV 查看各条光线。把输出 CSV 作为另一个系统的入瞳时，需自行对准局部坐标系；交换格式只传二维复场或 Stokes，不传方向或 Ez。

## 第二部分　程序结构和算法

### 1. 模块和调用关系

主流程为 `prt_gui → prt_gui_trace → prt_trace → prt_intersect / prt_interface`。追迹完成后计算出瞳、像面和入瞳显示数据，再由 GUI 绘图或导出。

| 模块 | 文件 | 职责 |
|---|---|---|
| 界面与示例 | `prt_gui.m`、`prt_example_triplet.m` | LDE 编辑、位姿、导入导出、结果显示；提供默认处方。 |
| 处方和位姿 | `prt_lde_model.m`、`prt_scene_model.m` | 传播介质、STOP、厚度与各面独立位姿；把膜层 nm 转成 mm。 |
| 偏振输入与交换 | `prt_polarization.m`、`prt_load_pupil.m`、`prt_save_pupil.m`、`prt_pupil_csv_columns.m` | 统一偏振表示，处理入瞳和结果 CSV。 |
| 求交与传播 | `prt_sag.m`、`prt_intersect.m`、`prt_trace.m` | 矢高、法线、前向交点、通光裁剪、逐面历史和光程。 |
| 界面与膜系 | `prt_interface.m`、`prt_coating.m` | 折反射方向、复数 Fresnel 系数、各向同性多层膜。 |
| 出入瞳与结果 | `prt_pupil_frames.m`、`prt_exit_pupil.m`、`prt_gui_trace.m` | 近轴瞳或手动参考面；计算各面局部偏振与有效掩膜。 |
| 布局和椭圆 | `prt_scene_mesh.m`、`prt_scene_rays.m`、`prt_draw_scene.m`、`prt_pupil_ellipses.m`、`prt_ellipse.m` | 玻璃示意网格、轨迹抽样、局部偏振椭圆及旋向箭头。 |

### 2. 入射采样、偏振态与坐标

默认在入瞳局部 XY 上生成圆形规则采样。CSV 导入时用原始坐标和行序直接发射光线。每个采样点沿入射方向投影到有限 OBJ 平面，随后按 LDE 顺序追迹。位姿采用右手旋转 `Rz*Ry*Rx`，追迹位置、方向和复电场使用全局三维向量。

Jones 直接作为一个偏振模式。对 Stokes，构造二维相干矩阵，从其特征值和正交特征向量得到最多两个统计不相干的 Jones 模式。每个模式独立传播，计算结果时相加强度和互谱项。相位约定为 `Re{E exp(iωt−ik·r)}`，介质复折射率为 `n−iκ`，且 `S3=2 Im(conj(Ex)*Ey)`。按此约定，从接收侧面向光源观察，`[1;i]/sqrt(2)` 为顺时针右旋，`[1;-i]/sqrt(2)` 为逆时针左旋。

### 3. 几何求交、界面电场和薄膜

有独立位姿的光面先把光线转入局部坐标。圆锥部分用二次方程产生候选根，筛除反向根和错误分支；偶次非球面以圆锥根为初值，对矢高残差做带回溯的 Newton 迭代。由矢高偏导计算法线，并按局部通光范围裁剪，最后将交点及法线转回全局。

界面用入射方向和法线构造 s/p 基，将全局复电场投影到 s/p，乘以对应的复数透射或反射系数，再用出射 s/p 基还原为全局电场。裸界面使用 Fresnel 系数，折射方向满足 Snell 定律。有膜界面按实际入射角从基底反向递推 s/p 系数，将层内相位、相干多次反射和吸收包含在一个有效界面中。透射光线只在有实传播方向时成立，膜模型不计算层内横向位移。

### 4. 参考面、相位和输出

共轴自动瞳用近轴传递矩阵将 STOP 分别成像到物方和像方。手动模式直接使用指定平面。出瞳从最终实际光面后的光线状态独立求交，允许反向延长到虚出瞳，不受 IMA 裁剪。像面使用最终 IMA 的命中位置。程序将复电场转到对应平面的局部坐标后，以横向分量计算 Stokes 和椭圆。

光程为沿线段累加的 `n * 传播距离`，并加入入瞳到 OBJ 的参考偏移。勾选相位时，几何传播相位采用各输出面首条有效光线为常量参考；膜系相位始终保留。方位角为 `atan2(S2,S1)/2`，部分偏振光的椭圆率角取偏振分量。圆偏振与非偏振光的方位角无定义。

`prt_pupil_csv_columns` 为导入和偏振态导出提供同一表头。导出使用有效掩膜及输出面的局部 XY，不做插值或把重合光线相加。MAT 中的 `result.input`、`result.exitPupil`、`result.image` 对应三个参考面，`result.history{h}.coating` 存有带膜界面的复系数和入射余弦，索引为该历史项的 `rayIndices(valid)`。

### 5. 验证、示例出处与适用范围

```matlab
test_prt
test_prt_lde
test_prt_polarization_coating
test_prt_pupils
test_prt_scene
test_prt_triplet
test_prt_pupil_import
```

默认库克三片式几何来自 [Optiland 的公开处方](https://github.com/optiland/optiland/issues/710)。示例用 SCHOTT N-SK16 / F2 的 d 线折射率，在当前单波长追迹器中调焦。有效焦距约 50.02 mm，设定后焦距 42.245 mm，默认轴上几何 RMS 斑点半径约 4.05 μm。更换波长需更新输入的折射率。

程序按指定的 LDE 面序访问，像面结果是几何交点上的偏振样本。当前无衍射叠加、像面辐照度、点间相干场重采样、自动光线瞄准或非序列杂散光。`prt_overlap.m` 是已有的复场重叠工具，要求共面共基并提供合适权重。当前实现按两束共同非零区域归一化，存在不同截光或覆盖范围时，不能用作全探测面混频效率；两臂的拍频相位还需要统一相位参考。
